# Dialog

A modal window for a focused task, such as a form.

[Source](https://github.com/FalkorDB/falkordb-ui/blob/main/src/components/dialog.tsx) · [Radix Dialog](https://www.radix-ui.com/primitives/docs/components/dialog)

<Canvas of={DialogStories.Default} />

## Import

```tsx
import {
	Dialog,
	DialogClose,
	DialogContent,
	DialogDescription,
	DialogFooter,
	DialogHeader,
	DialogTitle,
	DialogTrigger,
} from "@falkordb/ui";
```

## Usage

```tsx
<Dialog open={open} onOpenChange={setOpen}>
	<DialogTrigger asChild>
		<Button>New graph</Button>
	</DialogTrigger>
	<DialogContent>
		<DialogHeader>
			<DialogTitle>Create graph</DialogTitle>
			<DialogDescription>Give the new graph a name.</DialogDescription>
		</DialogHeader>
		<Input aria-label="Graph name" />
		<DialogFooter>
			<DialogClose asChild>
				<Button variant="cancel">Cancel</Button>
			</DialogClose>
			<Button onClick={create}>Create</Button>
		</DialogFooter>
	</DialogContent>
</Dialog>
```

## Parts

| Part                               | Description                                                              |
| ---------------------------------- | ------------------------------------------------------------------------ |
| `Dialog`                           | Root. Holds `open`, `onOpenChange` and `defaultOpen`.                    |
| `DialogTrigger`                    | The element that opens it.                                               |
| `DialogContent`                    | The window. Portalled, with a backdrop and a close button in the corner. |
| `DialogHeader`, `DialogFooter`     | Layout rows for the title and the actions.                               |
| `DialogTitle`, `DialogDescription` | Name and describe the dialog for screen readers.                         |
| `DialogClose`                      | Closes the dialog when clicked.                                          |
| `DialogOverlay`, `DialogPortal`    | Lower-level pieces, for building custom content.                         |

### `DialogContent` props

Accepts the props of [Radix `Dialog.Content`](https://www.radix-ui.com/primitives/docs/components/dialog#content), plus:

| Prop               | Type      | Default | Description                                               |
| ------------------ | --------- | ------- | --------------------------------------------------------- |
| `hideCloseButton`  | `boolean` | `false` | Removes the corner close button.                          |
| `overlayClassName` | `string`  | —       | Classes for the backdrop, which `className` cannot reach. |

## Accessibility

- Always render a `DialogTitle`. If it should not be visible, hide it with `className="sr-only"`.
- The corner close button is labelled "Close". Escape and clicking the backdrop also close the dialog.
- Focus is trapped inside while it is open and returns to the trigger when it closes.
