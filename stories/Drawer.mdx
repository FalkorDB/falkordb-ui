# Drawer

A panel that slides in from the edge of the screen and can be dragged closed. Suits touch layouts.

[Source](https://github.com/FalkorDB/falkordb-ui/blob/main/src/components/drawer.tsx) · [Vaul](https://vaul.emilkowal.ski/)

<Canvas of={OverlaysStories.BottomDrawer} />

## Import

```tsx
import {
	Drawer,
	DrawerClose,
	DrawerContent,
	DrawerDescription,
	DrawerFooter,
	DrawerHeader,
	DrawerTitle,
	DrawerTrigger,
} from "@falkordb/ui";
```

## Usage

```tsx
<Drawer>
	<DrawerTrigger asChild>
		<Button>Add user</Button>
	</DrawerTrigger>
	<DrawerContent>
		<DrawerHeader>
			<DrawerTitle>Add user</DrawerTitle>
			<DrawerDescription>Grant access to this FalkorDB instance.</DrawerDescription>
		</DrawerHeader>
		<DrawerFooter>
			<Button>Create</Button>
			<DrawerClose asChild>
				<Button variant="cancel">Cancel</Button>
			</DrawerClose>
		</DrawerFooter>
	</DrawerContent>
</Drawer>
```

### Side drawers

`side` places the panel and its grab handle. Set vaul's `direction` on the root to the same edge so dragging closes it the right way:

```tsx
<Drawer direction="left">
	<DrawerContent side="left">…</DrawerContent>
</Drawer>
```

## Parts

| Part                               | Description                                                                                                    |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| `Drawer`                           | Root. Accepts [vaul's root props](https://vaul.emilkowal.ski/api). `shouldScaleBackground` defaults to `true`. |
| `DrawerTrigger`                    | The element that opens it.                                                                                     |
| `DrawerContent`                    | The panel, with a backdrop and a grab handle. Portalled.                                                       |
| `DrawerHeader`, `DrawerFooter`     | Layout rows for the title and the actions.                                                                     |
| `DrawerTitle`, `DrawerDescription` | Name and describe the drawer for screen readers.                                                               |
| `DrawerClose`                      | Closes the drawer when clicked.                                                                                |
| `DrawerOverlay`, `DrawerPortal`    | Lower-level pieces, for building custom content.                                                               |

### `DrawerContent` props

| Prop               | Type                            | Default    | Description                        |
| ------------------ | ------------------------------- | ---------- | ---------------------------------- |
| `side`             | `"bottom" \| "left" \| "right"` | `"bottom"` | The edge the panel is anchored to. |
| `handleClassName`  | `string`                        | —          | Classes for the grab handle.       |
| `overlayClassName` | `string`                        | —          | Classes for the backdrop.          |

The panel pads itself for safe-area insets, so it clears notches and home indicators on phones.
